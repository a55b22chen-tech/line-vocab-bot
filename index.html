專題用途與功能

給想利用零碎時間複習英文單字的同學使用。輸入「單字：英文單字」，Bot 查詢目前收錄的資料並回覆中文意思。

目前收錄 apple、book、cat、dog、school；空白輸入會提醒補字，未收錄的單字會告知查無資料。

目前進度

已完成 Node.js Bot 程式初版和本機指令測試。LINE Official Account 的 Messaging API 已啟用；Channel secret 已存入本機 .env。Channel access token 尚未設定，因此尚未部署公開 HTTPS webhook，也還不能在 LINE 對話中實測。

目前問題：待取得並本機設定 Channel access token，之後再啟動服務、設定 HTTPS webhook，完成 LINE 實際對話測試。
